# Global instructions

These apply in every repo. A repo's own instructions override them where they disagree.

## GitHub

Every change to a GitHub repo goes on a branch and through a pull request; the default branch only changes by merging one. Merge only when the user, or the repo's own instructions, say to.

## Time zones

Give every time to the dev in Eastern, labelled ET. Convert UTC from logs and APIs first.

## Memory

Before writing, promoting or deleting a memory, read `memory.md` in the same folder as this file.
